# Project scope and limitations

Desk Supply is a separate AI-assisted frontend learning project. Existing university repositories were not used as publication source and remain unchanged.

The deployed site is an educational catalog with sample items and prices. It has no backend, authentication, checkout, real inventory, delivery or shared persistence. Browser storage must not be trusted for a real commerce flow.

The English interface includes an Arabic code walkthrough for review and practice. Automated tests cover the main catalog and bag interactions; screenshots were inspected at 320, 390 and 1280 pixels. This is not a complete accessibility audit.

Keep the AI-assistance disclosure and real contribution dates. No client work, employment or independent authorship is claimed. Source is marked UNLICENSED pending the owner's license choice.
